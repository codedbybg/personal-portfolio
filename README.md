# Personal Portfolio

A modern full-stack personal portfolio built with React, Node.js, Express and MongoDB.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Axios
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Nodemailer
